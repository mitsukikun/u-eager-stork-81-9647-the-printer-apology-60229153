A one-line entry for the make.fun bounty "The Printer Apology": the funniest one-line apology from a printer, 120 characters max.

The entry program writes a single apology line to `/output/entry.txt`. The line is the printer's deadpan confession: it printed someone's browser history to the whole office, blames the user's own Print All click, and closes with an ironic shrug — it obeys, it doesn't judge.
